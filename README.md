# Kart Eşleştirme

100 bölümlük bağımsız HTML kart eşleştirme oyunu.

## Test kısayolları
- **A** = sonraki bölüm (kilitli olsa da test için atlar).
- **S** = 1. bölüme dön (kaydedilen ilerlemeyi sıfırlamaz).
- Telefonda bölüm menüsü kullanılır.

## Web testi
GitHub → **Settings → Pages** → Source: **Deploy from a branch** → **main / (root)** → Save.
GitHub hesabının özel depolarda Pages desteği gereklidir; bu destek yoksa özel depoyu izinsiz herkese açık yapmayın. Yayın etkinleştikten sonra beklenen adres:
https://kelacumelam-cyber.github.io/kart-eslestirme/

## Yol haritası
1. Farklı dünyalar ve bölüm mekanikleriyle tekrarı azalt.
2. Günlük seri ve yinelenen emoji hatalarını düzelt.
3. Mobil ekran/UX testleri.
4. Finalde Capacitor Android APK, uygulama seviyesinde **portrait ekran kilidi** ve gerçek telefon kabul testi.
